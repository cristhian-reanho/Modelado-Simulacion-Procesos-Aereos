# Modelado y Simulación de Procesos Operativos Aéreos

Proyecto académico desarrollado para el curso de Modelado y Automatización de Procesos Empresariales de la Pontificia Universidad Católica del Perú.
El proyecto analiza procesos operativos de una aerolínea mediante levantamiento de información, modelado BPMN y simulación de procesos, con el objetivo de identificar oportunidades de mejora y automatización.
Para el entregable final se profundizó en los procesos de Despegue y monitoreo de sistemas y Aterrizaje del avión, dos procesos interdepartamentales que involucran coordinación entre diferentes actores de la operación aérea.     MAPE Proyecto Integrador (Final…
## Procesos analizados

Durante el proyecto se trabajó con procesos vinculados a la operación aérea.
Para el entregable final se profundizó en dos procesos interdepartamentales:

### Despegue y monitoreo de sistemas

Comprende actividades desde la autorización y carrera de despegue hasta el
monitoreo de sistemas durante el vuelo, incluyendo decisiones ante fallas,
emergencias y coordinación con control de tránsito aéreo.

### Aterrizaje del avión

Comprende la preparación para el descenso, configuración de la aeronave,
aproximación, posibles escenarios de go-around, aterrizaje, rodaje y llegada
a la posición final.

## Modelado de procesos

Los procesos fueron documentados y modelados utilizando:

- BPMN
- Bizagi Modeler
- Draw.io

Se elaboraron diagramas de procesos con actividades, participantes,
eventos, decisiones y flujos de coordinación entre los distintos actores.

## Simulación

Se realizó la simulación del proceso de aterrizaje utilizando Bizagi,
considerando distintos escenarios y parámetros de:

- tiempo;
- recursos;
- validaciones del proceso;
- utilización de participantes.

Los resultados permitieron analizar el comportamiento del proceso e
identificar oportunidades de mejora.

## Indicadores

Como parte del análisis se plantearon indicadores para evaluar el desempeño
de los procesos, considerando aspectos como tiempos operativos, respuesta
ante emergencias y resultados del proceso.
